<br>

PythaLab is a research lab at Yildiz Technical University led by Asst. Prof. Dr. Mehmet İşcan. We work on
flight control for unmanned aircraft, reinforcement learning built on optimal control, and the use of LLM
agents in engineering. Our work runs from the equations to the simulator, the hardware loop and the
aircraft.

<p align="center">
  <picture><source media="(prefers-color-scheme: dark)" srcset="https://raw.githubusercontent.com/PythaLab/.github/main/profile/assets/v5/research-map-dark.svg"><img src="https://raw.githubusercontent.com/PythaLab/.github/main/profile/assets/v5/research-map-light.svg" alt="Research areas. UAV flight control: fixed-wing and tilt-rotor VTOL aircraft, learned policies on classical autopilots, 6-DOF digital twins, SIL/HIL and flight tests. Safe and optimal control: HJB and Bellman methods, approximate dynamic programming, MPC, safety filters and Lyapunov-based analysis. Estimation: Kalman filtering, unscented estimation of actuator parameters and sensor fusion for flight systems. Embedded control: real-time control and estimation code for microcontrollers, servo and sensor interfaces. LLM agents for engineering: validation-gated code generation with local models, agent memory and controlled evaluation of coding agents. Teaching: browser-based laboratories for reinforcement learning, machine learning and language models." width="100%"></picture>
</p>
